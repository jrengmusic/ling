# LING: Language Index Navigation Graph

**Version 0.0.1**

You see this guide because you ran `ling` with no argument or `ling --help`.

## Command Line

| Command                                                     | Result                                                                                                                                                                                                                                                                                                                                                                                          | Exit |
| :---------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--- |
| `ling`                                                      | Prints this guide.                                                                                                                                                                                                                                                                                                                                                                              | 0    |
| `ling --help`                                               | Prints this guide.                                                                                                                                                                                                                                                                                                                                                                              | 0    |
| `ling --version`                                            | Prints `ling 0.0.1 (<commit>)`.                                                                                                                                                                                                                                                                                                                                                                 | 0    |
| `ling <project-info.md>`                                    | Reads the manifest. For each language family, reads the compiler manifest that the default-flow `## toolchain` rows give, then parses each file of each unit. Prints one row per document in path order, `<path>: <declarations> declarations, <references> references`, then `<documents> documents`.                                                                                          | 0    |
| `ling <project-info.md> --<word>`                           | The same, with the `## toolchain` rows whose `argument` cell is `<word>`, as cast takes it.                                                                                                                                                                                                                                                                                                     | 0    |
| `ling <project-info.md>`                                    | Each failure prints `ling: <project-info.md>: <failure>` on stderr. The rows still print.                                                                                                                                                                                                                                                                                                       | 0    |
| `ling <missing>`                                            | Prints this guide, then `ling: <missing>: not found` on stderr.                                                                                                                                                                                                                                                                                                                                 | 1    |
| `ling <project-info.md> <other>`                            | Prints `ling: <other>: unknown flag` on stderr.                                                                                                                                                                                                                                                                                                                                                 | 1    |
| `ling daemon <project-info.md> [--<word>]`                  | Starts the daemon of the manifest and the toolchain argument when none runs, and exits at once when one runs. The daemon reads the manifest and parses each file, then writes its port file in ~/.cache/ling/<daemon>/ (%LOCALAPPDATA%\ling\<daemon>\ on Windows). It ends when no request comes for the timeout: 60000 ms by default, or the timeout row of a ## daemon table in the manifest. | 0    |
| `ling <operation> <project-info.md> [--<word>] <arguments>` | Sends the operation to the daemon of the manifest and the toolchain argument, and starts the daemon with `ling daemon` when none answers. Prints one JSON array on stdout. A failure prints `ling: <operation>: <failure>` on stderr, and the first argument names the failure, as in the manifest run.                                                                                         | 0    |
| `ling <operation> <project-info.md> <wrong arguments>`      | Prints `ling: <operation>: wrong arguments` on stderr, and `[]` on stdout.                                                                                                                                                                                                                                                                                                                      | 0    |
| `ling <operation> <project-info.md> [--<word>] <arguments>` | Prints `ling: <operation>: daemon did not start` when the daemon cannot start, or `ling: <operation>: daemon connection lost` when the connection ends before the result, on stderr.                                                                                                                                                                                                            | 1    |

For the C family, LING reads `compile_commands.json` in the build folder that the `cmake` row names (`-B <folder>`), and the files of each unit from the record that `ninja -C <folder> -t deps` prints for the `ninja` row.

On a terminal, ling clears the screen first.

## Operations

| Operation              | Arguments          | Result                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :--------------------- | :----------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `goToDefinition`       | file, line, column | The declarations of the element at the position.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `findReferences`       | file, line, column | Each declaration of the element at the position, and the references to it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `hover`                | file, line, column | The declarations of the element at the position, each with its `scope`: the names of its path without the last one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `documentSymbol`       | file               | The declarations of that file as a tree, each with `children`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `workspaceSymbol`      | query              | Every declaration, in every document, whose name matches the query by fuzzy match. The order is the score of the match, then path, line, and column.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `completion`           | file, line, column | The declarations that the name before the column can complete to. The column is the cursor after the typed name. The client saves the file before it asks. The answer comes from the last parse of the saved file.                                                                                                                                                                                                                                                                                                                                                                                                     |
| `goToImplementation`   | file, line, column | For a class: each class that holds a `base` reference to it, and the classes that derive from those. For a member of a class: the members with the same name in those classes.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `prepareCallHierarchy` | file, line, column | The declarations of the element at the position that have the `function` role of the language.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `incomingCalls`        | file, line, column | For each `call` reference to those declarations: the declaration that is the parent of the reference.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `outgoingCalls`        | file, line, column | For each `call` reference below those declarations in the trees: its declarations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `switchSourceHeader`   | file               | The files of the manifest whose name, without its extension, equals the file's name and whose extension pairs with the file's extension under the language's extension pairs. Each entry holds only `path`. The order is the order of the files in the manifest.                                                                                                                                                                                                                                                                                                                                                       |
| `inlayHint`            | file               | Each `call` reference in the file, with `parameters`: the parameter texts of the first function declaration of the call, in path, line and column order; empty when the call has no function declaration.                                                                                                                                                                                                                                                                                                                                                                                                              |
| `diagnostics`          | file               | The compiler output of the check of the unit that compiles the file, unchanged; empty for a clean unit. The check is the unit's own compile command from the compiler manifest, plus the check flags of the C family (`-fsyntax-only`, the one-line msvc form and parseable fix-its on macOS, `/Zs /diagnostics:column` on Windows). A unit that loads the build's precompiled header uses LING's own copy in the cache folder of the daemon; LING writes nothing in the build folder. On macOS a fix that the compiler offers adds one line of the form `fix-it:"<file>":{<line>:<column>-<line>:<column>}:"<text>"`. |

Each entry is an object with `path`, `line`, `column`, `type`, and `name`. `hover` adds `scope`. `documentSymbol` adds `children`. `completion` adds `comment` (the source text of the comment above the declaration, with its markers) and, for a function, `snippet` (the name and one `${n:parameter}` placeholder for each parameter). `inlayHint` adds `parameters`. A `switchSourceHeader` entry holds only `path`. The entries are in the order of path, then line, then column, except `workspaceSymbol` (by score), `completion` (by score, then the path of the symbol), `documentSymbol` (by tree), and `switchSourceHeader` (by the order of the files in the manifest). `line` and `column` are 1-based, and the column counts bytes. `type` is the numeric value of `map::SyntaxTokenType`.
